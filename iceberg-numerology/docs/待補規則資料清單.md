# 待補規則資料清單

以下資料必須由後台資料表填寫，系統不得自行補假資料。

## 一、個性特質解析表

每個數字 1–9 至少需補：

- 標題
- 核心特質
- 正面特質
- 負面特質
- 恐懼
- 人際關係風格
- 事業傾向
- 成長建議

## 二、空缺數解讀表

每個空缺數 1–9 至少需補：

- 標題
- 簡短說明
- 完整說明
- 成長建議

## 三、流年內容表

每個流年 1–9 建議補 5 種內容類型：

- 總覽
- 核心事件
- 禁忌
- 建議
- 整體氛圍

## 四、分數診斷規則表

需補：

- 適用來源：國曆九宮格、農曆九宮格、訊息圖或全部來源
- 觸發條件
- 圖形組合
- 對應數字
- 基礎分數
- 診斷標籤
- 優先順序
- 同數字是否只取最高分

## 五、痛點對應表

需至少建立 9 類痛點：

1. 自我不了解
2. 重複失敗
3. 情緒內耗
4. 關係困擾
5. 工作迷惘
6. 金錢焦慮
7. 行動卡住
8. 選擇困難
9. 人生方向

## 六、服務導流表

每個痛點至少對應：

- 主要服務
- 次要服務
- 導流按鈕代碼
- 按鈕文字
- 目標網址

## 七、導流按鈕設定表

需補：

- 按鈕代碼
- 按鈕文字
- 目標網址
- 追蹤參數
- 關聯服務代碼

## 八、測試資料表

需人工驗證至少 10 筆生日案例，包含：

- 一般生日
- 主命數 1–9
- 卓越數
- 整數
- 大滿貫案例
- 雙流年期案例
- 農曆特殊案例

## 九、正式上線前禁止事項

- 不得使用假資料
- 不得顯示 TODO
- 不得顯示 placeholder
- 不得顯示 undefined
- 不得顯示 null
- 不得顯示 NaN
- 不得顯示 Error
- 不得承諾改運、保證成功、保證賺錢或保證感情結果
