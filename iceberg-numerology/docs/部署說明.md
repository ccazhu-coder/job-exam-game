## 二、Apps Script 部署流程

1. 打開 Google Sheets 後台資料庫。
2. 點選「擴充功能」→「Apps Script」。
3. 將 `Code.gs` 內容貼入 Apps Script。
4. 儲存。
5. 執行 `runFullInit()`。
6. 執行 `setAdminTokenOnce()` 設定後台金鑰。
7. 執行成功後，立刻清空函式中的明文金鑰。
8. 部署為 Web App。

## 三、Web App 設定

部署類型：網頁應用程式

- 執行身分：我
- 誰可以存取：任何人

## 四、前台網址

前台測驗頁：

```text
Web App 網址
```

後台管理頁：

```text
Web App 網址?page=admin
```

報告頁：

```text
Web App 網址?page=report&token=報告金鑰
```

## 五、後台登入金鑰

後台登入金鑰由 `setAdminTokenOnce()` 設定，系統只儲存雜湊值，不保留明文。
