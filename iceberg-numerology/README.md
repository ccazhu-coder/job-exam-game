# 冰山下數字靈數測驗工具｜100 正式營運版

本資料夾是「冰山下數字靈數測驗工具」正式營運版專案備份。

## 專案定位

使用者輸入國曆出生年月日後，系統會產出每人固定核心結果：

1. 國曆九宮格
2. 農曆九宮格
3. 訊息圖
4. 流年
5. 數字診斷

## 技術架構

- Google Sheets：正式後台資料庫
- Google Apps Script：後端、前台、報告頁、後台頁
- GitHub：程式版本備份與開發紀錄

## 目前版本

- 版本：100正式營運版-v4
- 型態：單檔 Apps Script `Code.gs`
- 狀態：可部署測試與進行規則資料填寫

## 重要限制

系統不得自動補假資料。以下資料需由後台資料表填入：

- 個性特質解析
- 空缺數解讀
- 流年內容
- 分數診斷規則
- 痛點對應
- 服務導流
- 導流按鈕網址

若內容不足，前台應隱藏區塊或顯示正式防呆訊息，不得顯示 TODO、placeholder、undefined、null、NaN、Error。
