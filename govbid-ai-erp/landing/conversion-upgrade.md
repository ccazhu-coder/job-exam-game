# GovBid AI ERP｜能成交的 SaaS 官網升級清單

## 目標
把目前 Landing Page 從「看起來不錯」升級成「能收名單、能預約、能成交」的 SaaS 官網。

---

## 1. 首屏 Hero 必須完成 3 件事

### 目前要強化
- 讓訪客 5 秒內知道這是什麼
- 讓訪客知道適合誰
- 讓訪客知道下一步要做什麼

### 建議文案

主標：
```text
AI 政府標案作業系統
```

副標：
```text
從找案、評估、提案、答詢、履約到收款，GovBid AI ERP 幫你把每個政府標案變成可管理、可追蹤、可複製的流程。
```

CTA：
```text
預約導入諮詢
申請首批內測
```

信任標籤：
```text
適合講師｜顧問｜協會公會｜教育訓練單位｜小型顧問公司
```

## 3. 痛點區要打中真實焦慮

標題：
```text
你不是不會接標案，是沒有一套能複製的作業系統
```

六個痛點：
```text
看到標案，不知道該不該投
服務建議書每次都從零開始
簡報答詢不知道評審會問什麼
得標後場次、講師、廠商與核銷資料混亂
收款、應收款、支出與押標金不好追蹤
每一案經驗沒有留下，下一案又重新摸索
```

---

## 4. 功能區要從「功能列表」改成「成果導向」

不要只寫：
```text
標案管理、CRM、財務管理
```

要改成：
```text
幫你判斷這案該不該投
幫你快速產出提案架構
幫你準備評審答詢攻防
幫你追蹤履約任務進度
幫你掌握應收款與支出
幫你累積下一案可複製的 SOP
```

---

## 5. 價格區要有「推薦方案」與「行動理由」

### 首批內測版｜NT$9,800
適合想先建立標案系統的人。

### 完整商用版｜NT$19,800【推薦】
適合準備正式用來接案、管理流程與提升提案效率的人。

### 顧問導入版｜NT$39,800 起
適合協會、公會、公司與團隊導入。

補一句：
```text
首批內測名額有限，優先開放給已有標案需求或正在準備接案者。
```

## 6. Contact 區要改成成交表單，不是一般聯絡表單

區塊標題：
```text
預約了解 GovBid AI ERP
```

副標：
```text
留下你的需求，我會協助判斷你適合內測版、完整商用版，或顧問導入版。
```

欄位：
```text
姓名／單位
聯絡方式
目前身分
想解決的問題
預計使用情境
```

按鈕：
```text
送出預約諮詢
```

送出後提示：
```text
已收到你的預約資料，我們將優先透過 LINE 或 Email 與你聯繫。
```

---

## 7. 官網必須接 LINE 成交流程

CTA 文案：
```text
想先了解是否適合你？可直接加入 LINE 預約導入諮詢。
```

LINE 區塊應包含：
- QR Code
- 加入 LINE 按鈕
- 內測名額說明
- 預約導入諮詢說明

---

## 8. 成交路徑

訪客進站後應該照這個流程走：

```text
看到痛點
→ 了解這是標案作業系統
→ 看到 Dashboard 產品感
→ 看到功能成果
→ 看到價格
→ 留資料或加 LINE
→ 預約諮詢
→ 成交內測版／商用版／顧問導入版
```
