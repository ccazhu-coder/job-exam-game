# GovOps OS｜第36檔：Apps Script正式API MVP對齊版

## 目標

讓 `govbid-os/app/index.html` 的正式前端按鈕，全部對應到 Apps Script 後端 action，避免前端已經有按鈕，但後端沒有函式或 action 名稱不一致。

本檔開始進入 MVP v1.0.0 的真正後端對齊階段。

---

## 一、MVP正式API入口

Apps Script 需支援：

- doGet(e)
- doPost(e)
- router(action, data)
- success(message, data)
- fail(message, data)

正式前端目前以 GET 方式呼叫：

```text
? action=後端動作名稱
```

後續可再升級成 POST。

## 五、正式回傳格式

所有 API 都必須回傳：

```json
{
  "success": true,
  "message": "中文訊息",
  "data": {}
}
```

錯誤也一律回傳中文：

```json
{
  "success": false,
  "message": "系統暫時無法完成操作，請稍後再試。",
  "data": {}
}
```

前端不得看到原始工程錯誤。

---

## 六、後端錯誤處理規則

Apps Script 內部可記錄真實錯誤到「錯誤紀錄」。

前端只回傳中文摘要。

例如：

- 缺少活動ID → 請先選擇活動。
- 找不到資料表 → 系統尚未初始化，請先初始化資料表。
- 權限錯誤 → 系統連線失敗，請確認服務設定。
- 未知錯誤 → 系統暫時無法完成操作，請稍後再試。
