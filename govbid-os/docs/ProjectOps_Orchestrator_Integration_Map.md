# ProjectOps ERP｜模組串連總控設計

## 一、目前狀態

目前系統已具備多個功能模組，但尚未完全由「專案主檔」統一串連。

本文件定義 ProjectOps Orchestrator 的正式串連規則。

---

## 二、最高層主軸

所有案源都必須先進入：

```text
00_專案主檔
```

專案主檔是所有後續流程的共同上游。

---

## 三、案源類型

```text
政府標案
自辦課程
合作課程
企業委託
政府補助案
其他
```

---

## 四、政府標案串連流程

```text
00_專案主檔
→ 01_標案池
→ 02_投標決策
→ 03_投標進度
→ 04_標案文件中心
→ 得標轉履約
→ 74_履約活動場次
→ 85_招生設定
→ 86_報名資料
→ 88_學員名冊
→ 96_學員資料庫
→ 90_履約工作任務
→ 103_Email通知佇列
→ 105_課前提醒紀錄
→ 結案報告
```

---

## 五、自辦課程串連流程

```text
00_專案主檔
→ 自辦課程企劃
→ 課程定價
→ 場次規劃
→ 74_履約活動場次
→ 85_招生設定
→ 86_報名資料
→ 88_學員名冊
→ 96_學員資料庫
→ 90_履約工作任務
→ 103_Email通知佇列
→ 105_課前提醒紀錄
→ 財務結算
→ 結案報告
```

---

## 六、核心 ID 串連規則

每一筆資料都應盡量保留以下欄位：

```text
專案ID
案源類型
標案ID
課程ID
場次ID
招生ID
報名ID
學員ID
任務ID
檔案ID
結案ID
```

---

## 七、專案建立時應自動做的事

### 政府標案

```text
建立專案主檔
建立標案池資料
建立機關 CRM
建立標案文件中心入口
```

### 自辦課程

```text
建立專案主檔
建立自辦課程資料
建立預設招生設定草稿
建立課程財務草稿
```

---

## 八、建立場次時應自動串連

```text
專案ID
案源類型
專案名稱
標案ID / 課程ID
場次ID
```

場次後續會接：

```text
招生
報名
名冊
CRM
派工
提醒
成果
結案
```

---

## 九、錄取後應自動串連

```text
報名資料
→ 錄取審核
→ 學員名冊
→ 學員資料庫
→ 學員參與歷程
→ Email通知
```

---

## 十、活動完成後應自動串連

```text
成果附件
→ 出席統計
→ 滿意度統計
→ 核銷附件
→ 結案報告
→ 交付包
```
