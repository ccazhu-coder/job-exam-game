# GovOps ERP 自用正式版｜V1 功能範圍與驗收目標

## 一、系統定位

GovOps ERP 自用正式版的目標，是將前面已完成的可商業化 GovOps / ProjectOps 模組，收斂成使用者可先自行營運的 ERP Runtime。

本階段不是重新開發 SaaS 商品，也不是只做首頁，而是把既有模組轉為可實際使用的營運系統。

## 三、第一版正式目標流程

```text
標案池
→ 投標
→ 得標
→ 履約
→ 招生
→ 報名
→ 派工
→ 通知
→ 執行
→ 核銷
→ 結案
→ CRM
```

同時支援：

```text
專案
→ 政府標案
→ 自辦課程
```

## 四、目前已補成 Runtime 的部分

目前已完成下列 Runtime 層：

1. ProjectOps Orchestrator Runtime  
   - 專案主檔
   - 政府標案 / 自辦課程雙案源
   - 專案建立、專案初始化、建立場次、建立招生

2. Project Detail Runtime  
   - 單一專案營運總控
   - 讀取場次、報名、名冊、CRM、任務、Email、檔案、財務、結案

3. Registration Runtime  
   - 報名摘要
   - 錄取後結轉名冊
   - 同步 CRM
   - 建立 Email 通知

4. Task Runtime  
   - 場次任務初始化
   - 任務摘要
   - 任務提醒

5. Finance Runtime  
   - 應收
   - 收款
   - 支出
   - 核銷
   - 財務摘要

6. Closing Runtime  
   - 結案摘要
   - 缺件檢查
   - 結案主檔
   - 交付包

7. Unified Runtime  
   - ProjectOps Dashboard
   - 全域搜尋
   - 健康檢查

8. Document Runtime  
   - 結案報告資料組裝
   - HTML 交付版

## 五、下一步必補

目前 Runtime 已逐步成形，下一步不是再新增概念，而是補前端營運頁面，讓使用者可以直接操作。

P0 前端頁面：

- project-detail.html：單一專案營運中心
- tender-pool.html：政府標案池管理
- self-course.html：自辦課程管理
- execution-center.html：履約 / 開課執行中心
- finance-center.html：財務核銷中心
- closing-center.html：結案中心

## 六、第一版驗收標準

政府標案必須能跑完：

```text
新增標案
→ 投標決策
→ 得標轉履約
→ 建立場次
→ 建立招生
→ 報名同步
→ 錄取審核
→ 批次 Email
→ 產生名冊
→ 同步 CRM
→ 任務派工
→ 課前提醒
→ 上傳成果
→ 滿意度統計
→ 核銷附件
→ 產生結案報告
```

自辦課程必須能跑完：

```text
新增自辦課程
→ 定價
→ 建立場次
→ 建立招生
→ 報名 / 收款
→ 名冊
→ CRM
→ 任務派工
→ 開課提醒
→ 開課
→ 滿意度
→ 財務結算
→ 課後回流
→ 結案
```

## 七、判定原則

只有首頁不算完成。

只有文件不算完成。

只有模組存在不算完成。

必須能用真實專案跑完整流程，才算 GovOps ERP 自用正式版完成。
