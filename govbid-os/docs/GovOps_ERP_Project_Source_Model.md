# GovOps ERP｜案源類型模型：政府標案 × 自辦課程

## 一、核心修正

GovOps ERP 不應只支援「政府標案」。

系統第一層應改為：

```text
專案 / 案源
├── 政府標案
└── 自辦課程
```

後續流程共用：

```text
案源建立
→ 場次規劃
→ 招生報名
→ 錄取審核
→ 學員名冊
→ 任務派工
→ 課前通知
→ 開課執行
→ 出席 / 滿意度
→ 成果附件
→ 核銷 / 財務
→ 結案 / 成果報告
→ 學員 CRM
```

差別只在前段：

```text
政府標案：標案池、領標、投標、得標、契約、驗收
自辦課程：課程企劃、定價、銷售、招生、開課、營收結算
```

---

## 二、案源類型

### 1. 政府標案

適用流程：

```text
標案池
→ 領標
→ 投標決策
→ 投標
→ 得標
→ 簽約
→ 履約
→ 驗收
→ 結案
```

### 2. 自辦課程

適用流程：

```text
課程企劃
→ 課程定價
→ 招生頁 / 報名表
→ 報名收款
→ 開課
→ 課後服務
→ 成果整理
→ 財務結算
→ 學員 CRM
```

## 十、結論

GovOps ERP 第一版自用系統，不應只叫「標案 ERP」。

正確定位是：

```text
專案型課程與標案營運 ERP
```

其中：

```text
政府標案 = 一種案源
自辦課程 = 一種案源
```

後續招生、開課、派工、提醒、CRM、財務、結案，全部共用同一套營運流程。
