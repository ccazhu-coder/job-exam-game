# ProjectOps ERP｜專案型營運 ERP 正式版

## 一、產品定位

ProjectOps ERP 是一套用於管理「專案型營運」的自用 ERP。

支援案源：

- 政府標案
- 自辦課程
- 合作課程
- 企業委託
- 政府補助案
- 其他專案

核心原則：

政府標案與自辦課程只在前段不同，後段營運流程共用。

---

## 二、共用主流程

專案建立
→ 場次規劃
→ 招生設定
→ 報名管理
→ 錄取審核
→ 學員名冊
→ 任務派工
→ 課前提醒
→ 開課/執行
→ 出席統計
→ 滿意度
→ 成果附件
→ 財務核銷
→ 結案報告
→ CRM 經營

---

- 開始日期
- 結束日期
- 預算金額
- 營收目標
- 實際收入

- 更新時間

- 政府標案

- 其他

## 四、政府標案專屬流程

標案池
→ 領標
→ 文件解析
→ 投標決策
→ 投標作業
→ 得標/未得標
→ 得標轉專案履約

政府標案專屬欄位：

- 標案ID
- 機關名稱
- 採購類型
- 公告日期
- 截止日期
- 預算金額
- 押標金
- 履約保證金
- 領標狀態
- 投標日期
- 投標金額
- 決標結果
- 得標金額
- 簽約金額
- 契約日期
- 履約期間
- 驗收條件

- 優惠價

- 最低開課人數
- 開課成本
- 營收目標
- 報名費收入
- 實際開課人數
- 付款方式
- 退費規則

→ 產生名冊
→ 同步 CRM
→ 任務派工
→ 課前提醒
→ 開課
→ 滿意度統計
→ 財務結算
