# GovOps OS 模組流程架構 v2

> 本版補入履約執行階段前段核心：招生報名管理、錄取審核、通知、學員名冊、工作分配、場次任務派工。  
> 原則：標案、場次、資源、學員、工作任務皆只建立一次，後續用選單帶入與流程推進。

---

# 一、整體模組總架構

```text
SaaS 營運級骨架
├── Tenant Isolation 多租戶隔離
├── RBAC 權限系統
├── Audit Log 稽核日誌
├── Workflow Runtime 流程狀態機
├── Queue Persistence 持久化佇列
├── File Center 檔案中心
├── Notification Hub 通知中心（待補）
├── Settings Center 設定中心（待補）
├── Unified Search 全域搜尋（待補）
└── Dashboard Runtime 儀表板引擎（待補）

ERP 主檔資料層
├── 資源類型主檔
├── 講師基本資料
├── 工作人員基本資料
├── 合作廠商基本資料
├── 學員/客戶基本資料（需補強）
└── 場次/活動/課程主檔

標案生命週期
├── 標案搜尋與情報
├── 領標文件解析
├── 投標決策
├── 得標後建案
├── 履約執行
├── 驗收結案
└── 財務核銷與收款
```

---

# 二、標案前期流程

```text
每日標案查詢
↓
標案池
↓
全文檢索過去5年資料
↓
分析過往投標廠商、得標廠商、是否新案
↓
AI 勝率預測
↓
AI 競爭分析
↓
投標決策
↓
進入標案 Pipeline
```

---

# 三、領標與投標文件解析流程

```text
上傳領標資料
↓
File Center 登錄文件
↓
Queue Persistence 排入解析任務
↓
OCR / Parser / AI 文件分析
↓
解析招標公告、投標須知、工作說明書、契約草案
↓
判斷資格、履約期程、押標金、履約保證金、驗收條件、核銷條件
↓
產生心智圖、風險分析、投標任務
```

---

# 四、得標後建案流程

```text

↓
建立標案主檔

建立簽約金額、可請款金額、收款條件

建立履約時程

建立場次/活動/課程主檔
↓
建立招生/報名設定
↓
建立工作分配計畫
↓
進入履約執行
```

# 六、招生與報名管理流程（補入）

## 6.1 招生設定流程

```text
選擇標案
↓
選擇場次/活動/課程
↓
建立招生設定
├── 招生對象
├── 報名期間
├── 名額上限
├── 候補名額
├── 錄取規則
├── 是否需審核
├── 是否需繳費
├── 是否需資格文件
└── 通知模板
↓
產生報名連結 / 報名表
↓
開始招生
```

## 6.2 報名資料流程

```text
使用者填寫報名表
↓
報名資料進入 Registration DB
↓
自動去重
↓
資格初篩
↓
進入待審核
↓
錄取 / 候補 / 不錄取
↓
產生學員名冊
↓
同步通知
↓
同步場次應出席人數
```

## 6.3 報名管理應有狀態

```text
待審核
已錄取
候補
不錄取
已通知
已取消
未報到
已報到
已完訓
```

## 6.4 報名管理需要資料表

```text

86_報名資料
87_錄取審核紀錄
88_學員名冊
89_報名通知紀錄
```

## 6.5 報名資料核心欄位

```text

標案ID

活動名稱
活動日期
姓名
身分證後四碼或識別碼
電話
Email
LINE ID
身分類別
資格文件
報名狀態
審核狀態
錄取狀態
通知狀態
報到狀態
完訓狀態
備註
```

# 九、工作分配 / 任務派工流程（補入）

## 9.1 工作分配主流程

```text
選擇標案
↓
選擇場次
↓
建立任務清單
↓
指派負責人
├── 專案經理
├── 行政人員
├── 現場工作人員
├── 講師
├── 助教
├── 攝影紀錄
├── 財務核銷
└── 合作廠商
↓
設定截止日
↓
設定提醒
↓
追蹤完成狀態
↓
逾期提醒
↓
同步履約狀態
```

## 9.2 場次工作任務範本

```text
課前30天：確認講師
課前21天：完成招生頁
課前14天：確認報名名單
課前7天：寄送課前通知
課前3天：確認場地與設備
課前1天：準備簽到表、教材、物資
活動當日：報到、拍照、簽到、現場紀錄
活動後1天：上傳照片、簽到表
活動後3天：彙整滿意度
活動後7天：完成核銷資料
活動後14天：完成結案資料
```

## 9.3 任務資料表

```text
90_履約工作任務
91_履約任務指派
92_履約任務提醒
93_履約任務完成紀錄
```

## 9.4 任務狀態

```text
待指派
待處理
執行中
待確認
已完成
逾期
取消
```

# 十三、滿意度流程

```text
場次完成
↓
選擇滿意度方式
├── 紙本問卷
│   ├── 上傳掃描檔
│   ├── 人工輸入統計
│   └── 後續OCR分析
└── 線上問卷
    ├── 貼 Google Form URL
    ├── 系統自動解析 Form ID
    ├── 系統自動取得回覆表
    └── 系統自動統計
↓
平均分數
↓
滿意度百分比
↓
意見摘要
↓
改善建議
↓
同步結案報告
```
